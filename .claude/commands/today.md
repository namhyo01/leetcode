오늘의 문제를 내라. `CLAUDE.md`의 코치 지침을 그대로 따른다.

1. 먼저 `README.md` 진행 표에서 **재풀이 날짜가 오늘 이전인 문제**가 있는지 확인한다.
   있으면 새 문제 대신 그 문제의 재풀이를 꺼낸다. 이때 기존 풀이 파일은
   `git mv` 하지 말고, 사용자가 백지에서 다시 칠 수 있도록 템플릿으로 비운 뒤
   원래 풀이는 `git show`로 언제든 꺼낼 수 있다고 안내한다.

2. 재풀이 대상이 없으면 `POOL.md`의 미완료(`- [ ]`) 항목에서 **랜덤으로** 하나 고른다.
   난이도가 과하게 튀면(오늘 이미 실패한 직후 등) 그 사실을 알리고 사용자에게 선택권을 준다.

3. 문제 디렉토리를 만들고 **영문 지문 README + 빈 템플릿 + 테스트 하네스**를 생성한다.
   - 유형(알고리즘)은 어디에도 적지 않는다
   - 하네스의 기댓값은 참조 구현으로 검증하되, 참조 구현은 저장소에 남기지 않는다
   - Go는 `package main` + `main()` 놀이터

4. 채팅에 **영어 지문 + 예제 + 제약조건**을 텍스트로 정리해 보여주고,
   실행 명령과 채울 함수 시그니처를 안내한다.

5. 여기까지 커밋 + 푸시한다. 풀이는 사용자 몫이므로 절대 채우지 않는다.
