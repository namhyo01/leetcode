사용자가 문제를 다 풀었다. `CLAUDE.md`의 코치 지침을 따른다.

1. 사용자가 작성한 `solution.py` / `solution.go`를 읽는다.
2. 두 언어 테스트를 모두 돌린다. 실패하면 **정답을 알려주지 말고** 어떤 케이스가
   왜 깨지는지만 보여주고 스스로 고칠 기회를 준다.
3. 통과하면 리뷰한다. 성능을 언급할 거면 **추측하지 말고 벤치마크로 측정**한다.
4. 사용자에게 이번 문제의 유형이 무엇이었는지, 왜 그 유형인지 이제 알려준다.
5. 기록을 갱신한다:
   - 문제 `README.md`의 "내 접근" 회고 섹션 (한국어)
   - 루트 `README.md` 진행 표 — 유형 칸을 채우고, 상태를 ⬜/❌/🟡/✅ 중 **정직하게** 표기
   - `POOL.md` 체크박스
6. 커밋 + 푸시한다. 커밋 메시지는 한국어, 접근법과 복잡도를 요약한다.
